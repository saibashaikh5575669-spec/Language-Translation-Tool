# Language Translation Tool

This is a simple language translation tool made using Python.

## Features

- Enter text to translate
- Select source language
- Select target language
- Translate text
- Clear input and output

## Technologies Used

- Python
- Tkinter
- deep-translator

## How to Run

1. Install Python.
2. Install the required library:

pip install deep-translator

3. Run the program:

python translator.py

## How It Works

The user enters text and selects the source and target languages.
The program uses the deep-translator library to translate the text
and displays the translated result.
